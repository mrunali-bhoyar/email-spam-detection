# Email Spam Detection Using Machine Learning

## Project Overview
This project compares four machine learning classification algorithms for detecting spam emails: Support Vector Machine (SVM), Decision Tree, K-Nearest Neighbors (KNN), and Gaussian Naive Bayes.

## Dataset
The project uses the UCI Spambase dataset, containing 4,601 email records with 57 numerical features and a binary class label.

Dataset source: https://archive.ics.uci.edu/dataset/94/spambase

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn

## Models Implemented
1. Support Vector Machine (SVM)
2. Decision Tree
3. K-Nearest Neighbors (KNN)
4. Gaussian Naive Bayes

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Log Loss

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. Ensure an internet connection is available to load the dataset.
4. Review the comparison table, evaluation graphs, and confusion matrices.

## Objective
To compare the performance of different classification algorithms and understand their suitability for email spam detection.
